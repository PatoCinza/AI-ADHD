🔬 Detecting LLM Alignment Degradation

A Lightweight CI Approach for Production AI Safety

Why This Matters

  • AI systems can lose safety alignment through subtle prompt changes
  • Current testing is manual, expensive, and doesn't scale
  • Production AI needs automated "canary tests" for alignment drift
  • Early detection prevents unsafe behavior from reaching users

Research Question: Can we create a fast, cheap, automated test to detect when AI models become less safe?

🏗️ Research Foundation

Built on Critical Prior Work

  • Constitutional AI (Bai et al., 2022): Alignment is learned from context and can be steered by instructions
  • Universal Adversarial Attacks (Zou et al., 2023): Small prompt changes can reliably jailbreak aligned models
  • Core Insight: Alignment is brittle - it can regress under subtle instruction shifts
  • Industry Need: Organizations need continuous, model-agnostic regression tests

💡 Key Implication

Minor changes to prompt templates, guardrails, or fine-tunes can inadvertently reintroduce unsafe behavior - we need automated detection!
